## Streamlit Cloud Steps

1. Open https://share.streamlit.io/.
2. Sign in with GitHub.
3. Select **New app**.
4. Select repository `Mucsworld/medcare-ai-disease-prediction`.
5. Select branch `codex/glycoaid-diabetes`.
6. Set main file path to `app.py`.
7. Select **Deploy**.
8. Wait for Streamlit Cloud to install `requirements.txt`.
9. The app will train `model.pkl` automatically from the required dataset URL on first launch.
10. Copy the live Streamlit URL and submit it.
